# Magic Trackpad 2 USB 社区修复版

基于 [imbushuo/mac-precision-touchpad](https://github.com/imbushuo/mac-precision-touchpad)，保留原作者贡献、提交历史和许可证。这不是 Apple 或原作者发布的官方版本。

**当前阶段：源码预览，尚无面向普通用户的正式签名安装包。** 本机开发版本为 `2026.922.4.0`，本地开发证书不作为大众发行方案。

## 首版范围

Magic Trackpad 2 **Lightning、有线 USB、Windows 11 x64**，硬件 ID `USB\VID_05AC&PID_0265&MI_01`。目前只在一台实际设备验证。蓝牙、USB-C、ARM64、Windows 10、MacBook 内置触摸板均不承诺支持此次修复。

## 已完成

- 四边各 5% 的边缘起始屏蔽，持续到触点抬起；从中央滑到边缘保持有效。
- 修复第二根手指悬空靠近时被错误当成按下、造成指针漂移的问题。
- 大面积误触需连续三帧确认，减少正常双指滚动中的瞬间误判。
- 修正抬手坐标、触点生命周期、扫描时间和极端坐标处理。
- Windows 11 专用 USB 安装文件通过新 WDK 检查。

自动化测试和本机实测已通过，包括用户确认悬空触发漂移消失；这不等于已完成广泛兼容性认证。

## 已知限制

边缘宽度仍是编译参数，边缘起始的有意操作也会被屏蔽。旧设置界面的灵敏度参数仍未接入此路径。不能区分手腕或手指造成的物理按压。原通用多设备安装包仍有独立问题。

## 使用与开发

目前请以 [开发说明](docs/community-development.md) 和 [发布计划](docs/public-release-plan.md) 为准。原版安装说明仅保留在 [上游历史 README](docs/upstream-README.md)，不适用于改动后的安装包。

USB 驱动继续使用原来的 [GPLv2](LICENSE-GPL.md)。今后发布二进制时，应同时提供对应版本的完整修改源码和构建材料。不要把本机证书私钥、原驱动备份或含个人设备信息的日志提交到仓库。
